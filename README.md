## 实验一：专注计数（复现 Most et al., 2001, Psych Science, Exp.1）

- **范式**：灰色窗口内 8 个 L/T 形（白色目标 + 黑色干扰）随机运动反弹；被试默数**白色**图形碰边总次数。先 1 轮练习（不计成绩），再 3 轮正式计数（每轮 15 s）：前 2 轮无意外物，第 3 轮（关键轮）第 5 s 起一个**白色十字**从右向左横穿画面，可见 5 s。之后按原文附录顺序问询：①有没有看到其他东西 → ②描述 → ③颜色 → ④方向 → ⑤形状（没看到也猜，并区分"看到/猜测"）。第 4 轮为**全注意对照**（不计数，只看，十字再次出现）。
- **自变量**：意外十字颜色 × 被试注意颜色。本作业固定注意 = 白色、十字 = 白色（即原文"颜色匹配"格，原文注意到率 94%）。
- **因变量**：关键轮是否注意到意外物（0/1，主 DV）；计数误差；全注意轮注意到率（操作检验）。
- **出处**：Most, S. B., Simons, D. J., Scholl, B. J., Jimenez, R., Clifford, E., & Chabris, C. F. (2001). *Psychological Science*, 12(1), 9–17.

### 改进想法与预测（收数前写定，见 git 提交记录）

- **改进**：**知觉负荷 = 白色目标数量（Lavie set-size load）**（被试间随机分配）：
  - `low`（低负荷）：画面 2 白 + 6 黑，只数白色图形碰边次数（目标少→负荷低）；
  - `high`（高负荷）：画面 6 白 + 2 黑，只数白色图形碰边次数（目标多→负荷高）。
  - 两种条件**都只数白色**，避免"同时数两种颜色"造成的工作记忆过载，使负荷差异更干净地来自目标追踪数量（而非任务切换）。
- **理论依据**：知觉负荷理论（Lavie, 1995, 2005）——中央任务的目标数量（set size）决定知觉负荷，负荷越高、对任务无关刺激的加工越少；Simons & Chabris (1999) 难/易任务注意到率 42% vs 58%/68%。
- **预测**：高负荷组在关键轮对白色十字的注意到率**低于**低负荷组；低负荷组（颜色匹配）应接近原文 94% 的高注意到率；两组的计数误差相近（排除"高负荷组只是没数对"的解释）。
- **条件平衡**：负荷条件由网页 `Math.random() < .5` 随机分配；十字出现高度自动避开白色图形聚集侧。

## 实验二："你在这里"地图（复现 Levine, 1982）

- **范式**：左边第一人称视野（正面朝某栋楼），右边校园导览图，红点"你在这里"。要求尽快判断某栋楼在**自己的**前/后/左/右（方向键，超时 9 s）。注视点 300 ms，ITI 350 ms，反馈闪现。练习 2 次 + 正式 24 次。
- **自变量**：地图朝向（对齐 0° ×12 vs 不对齐 90°/180°/270° 各 ×4，被试内混合随机）；**改进自变量**：朝向线索（有/无，被试内各半，与朝向交叉平衡）。
- **因变量**：正确率、正确试次 RT。
- **出处**：Levine, M. (1982). *Journal of Experimental Psychology: Human Perception and Performance*, 8(1), 157–175（You-are-here 地图）。

### 改进想法与预测（收数前写定，见 git 提交记录）

- **改进**：**朝向线索**——一半试次在地图上额外画一个红色箭头，从"你在这里"指向你正面那栋楼在地图上的位置（即直接标出"你面朝这边"）。
- **理论依据**：空间参照系对齐 / 心理旋转（Shepard & Metzler, 1971；Hintzman et al., 1981）——不对齐地图的代价来自把地图参照系旋转到与自我参照系一致；外部朝向线索可直接完成该对齐，无需心理旋转。
- **预测**：
  1. 复现 Levine：不对齐·无线索 条件正确率最低、RT 最长（尤其 180°），且错误多为"按地图上方 = 前方"读出的方向；
  2. 改进效应：有线索时，不对齐代价（不对齐 − 对齐的 RT 差与正确率差）**大幅缩小甚至消失**；线索在对齐条件下几乎无影响（天花板）。
- **条件平衡**：线索 × 朝向 × 目标方向在试次表内交叉平衡后统一打乱；四个地标名每试次从 8 个地标中随机抽取。

## 实际结果与分析（n = 10）

> 数据于 2026-11-08 收集，10 名被试（匿名昵称）。以下分析基于后台下载的 CSV。

### 实验一：专注计数（n = 10）

| 条件            | n（被试） | 注意到人数 | 注意到率     |
| ------------- | ----- | ----- | -------- |
| 低负荷（2 白目标，复现） | 4     | 4     | **100%** |
| 高负荷（6 白目标，改进） | 6     | 6     | **100%** |

- 原文 Most et al. (2001) 颜色匹配条件注意到率：**94%**。
- **预测检验**：预测"高负荷组注意到率低于低负荷组"——**未成立**，两组均 100%，与原文同一方向。
- **可能原因**：①为照顾计数难度，图形速度大幅放慢（40–70 px/s vs 原版 128–320 px/s），画面整体知觉负荷可能偏低，两组均未达到"负荷饱和"，十字的显著度足以被注意到；②白色十字较大（96 × 96 px）、可见时间长（5 s），在慢速画面中显著度高；③样本量仍偏小（10 人，高负荷 6 / 低负荷 4），统计效力不足；④全注意对照轮通过率 100%，操作检验有效。
- **计数能力平衡**：低负荷组前两轮平均误差 ±0.7，高负荷组 ±1.3，两组计数能力接近，排除了"高负荷组只是没数对"的替代解释。

### 实验二：YAH 地图（n = 10，240 试次）

**2×2 正确率与中位 RT（正确试次）：**

| 条件      | 正确率   | 中位 RT (ms) | n（试次） |
| ------- | ----- | ---------- | ----- |
| 对齐·无线索  | 96.7% | 2536       | 60    |
| 对齐·有线索  | 96.7% | 2140       | 60    |
| 不对齐·无线索 | 86.7% | 3480       | 60    |
| 不对齐·有线索 | 96.7% | 2795       | 60    |

**汇总：**

|       | 对齐 (0°) | 不对齐 (90/180/270°) |
| ----- | ------- | ----------------- |
| 正确率   | 96.7%   | 91.7%             |
| 中位 RT | 2478 ms | 3284 ms           |

|       | 有线索     | 无线索     |
| ----- | ------- | ------- |
| 正确率   | 96.7%   | 91.7%   |
| 中位 RT | 2463 ms | 2849 ms |

**不对齐代价（不对齐 − 对齐 的 RT 差）：**

- 无线索：**944 ms**（3480 − 2536）
- 有线索：**655 ms**（2795 − 2140）
- 线索将不对齐代价**缩小了 289 ms（−31%）**。

**预测检验：**

1. ✅ **不对齐比对齐更慢**：3284 vs 2478 ms（+806 ms，+33%），成立。
2. ✅ **不对齐比对齐更易错**：91.7% vs 96.7%（−5.0 pp），方向正确。
3. ✅ **朝向线索缩小不对齐代价**：从 944 ms 降到 655 ms（−31%），成立。
4. ✅ **线索主要作用于不对齐条件**：不对齐时线索效应 685 ms（3480→2795），对齐时仅 396 ms（2536→2140），支持"线索提供外部参照系对齐"的机制解释。
5. ⚠ 180° 正确率应最低/RT 最长——本数据中正确率回升、中等 RT，与"180° 心理旋转代价最大"的经典预期不完全一致，可能因被试策略差异或天花板效应。

### 小结

- **实验二改进有效**：朝向线索显著缩小了不对齐代价（−31%）并提升正确率（86.7% → 96.7%），支持"外部参照系对齐可替代心理旋转"的理论预测。
- **实验一改进未显现效果**：两组注意到率均为 100%，无法区分负荷差异。若后续研究要检验该改进，需提高图形速度或增大目标数量差距。
